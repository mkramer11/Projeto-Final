Bem-vindo ao Meu Primeiro Site!

Este é um projeto desenvolvido para aprender programação, versionamento e colaboração utilizando Git.

Sobre o projeto

O objetivo deste site é demonstrar como diferentes desenvolvedores podem trabalhar simultaneamente em um mesmo projeto.

O que estou aprendendo?

  • Controle de versões com Git
  • Hospedagem de projetos no GitHub
  • Criação e gerenciamento de branches
  • Merge e Pull Requests
